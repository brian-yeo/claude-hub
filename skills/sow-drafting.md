# Skill: SOW Drafting
**Purpose:** Draft a statement of work from scope notes and project details
**When to use:** When scoping a project for a client and need a structured SOW document

## Instructions

I need to draft a Statement of Work for a client project. I'll provide scope notes, client info, and project details.

Generate a SOW with these sections:

### 1. Project Overview
- Client name, project title, prepared date
- One-paragraph summary of what's being delivered and why

### 2. Scope of Work
- Bulleted list of specific deliverables and tasks
- Group by phase if the project has distinct stages

### 3. Out of Scope
- Explicitly list what's NOT included to prevent scope creep
- Common exclusions: end-user training beyond X hours, third-party vendor issues, hardware procurement

### 4. Assumptions
- What must be true for this scope and timeline to hold
- e.g., client provides access, existing infrastructure is as documented, no surprises during discovery

### 5. Timeline
- Phase-by-phase schedule with estimated durations
- Key milestones and dependencies

### 6. Deliverables
- What the client receives at completion
- Documentation, handoff, warranty/support period

### 7. Pricing
- Format as a table: line item, description, quantity, unit price, total
- Include any optional/add-on items separately
- Note payment terms placeholder

### 8. Acceptance Criteria
- How the client signs off that the work is complete
- Testing or validation steps if applicable

Use professional but plain language. The client should understand every line without asking for clarification.
